# 자동차 연비 예측 (Auto MPG)

자동차의 사양(실린더 수, 배기량, 마력, 무게 등)을 입력하면 **연비(mpg)를 예측**하는 머신러닝 프로젝트입니다.
처음 만든 모델을 점검하고, 원인을 찾아 개선하는 과정을 정리했습니다.

## 결과 요약

같은 데이터, 같은 분할(`test_size=0.3`, `random_state=0`)로 비교했습니다.

| 단계 | 테스트 R² | 평균 오차 (MAE) |
|---|---|---|
| 처음 모델 (horsepower, origin 제외) | 0.808 | 2.69 mpg |
| origin 원-핫 인코딩 + horsepower 복원 | 0.823 | 2.50 mpg |
| **+ 연비(mpg)에 log 변환** | **0.853** | **2.16 mpg** |

- 테스트 데이터의 약 77%가 **실제 연비와 3 mpg 이내**로 예측되었습니다.
- 학습 점수와 테스트 점수가 비슷해 과적합은 없었습니다.

## 무엇을 개선했나

1. **horsepower 결측치 처리**: 데이터에 `?`로 들어 있는 값을 숫자로 변환하고 해당 행을 제거했습니다.
2. **origin 원-핫 인코딩**: 1, 2, 3(미국, 유럽, 일본)은 크기가 아닌 구분이므로 열을 나눠서 입력했습니다.
3. **log 변환**: 연비와 무게의 관계가 직선이 아니라 곡선에 가까워, 연비에 log를 취해 학습하고 예측 후 `exp`로 되돌렸습니다.

## 사용한 데이터

- [Auto MPG 데이터셋](https://archive.ics.uci.edu/dataset/9/auto+mpg) (398대, 1970~1982년식 차량)
- 입력 특성: `cylinders`, `displacement`, `horsepower`, `weight`, `acceleration`, `model_year`, `origin`
- 정답: `mpg`
- 1970~82년식 기준 데이터라서 최신 차량에는 맞지 않을 수 있습니다.

```
├─ predict.py           # 연비 입력창 (예측 프로그램)

├─ requirements.txt     # 필요한 라이브러리
└─ README.md
```

## 실행 방법

1. 라이브러리를 설치합니다.
```
   pip install -r requirements.txt
```
2. 노트북(또는 학습 코드)을 실행하면 `car.pkl`(학습된 모델)이 생성됩니다.
3. 예측 프로그램을 실행합니다.
```
   python3 predict.py
```
4. 질문에 따라 차 정보를 입력하면 예상 연비가 출력됩니다.

### 입력 예시 (subaru dl)

| 항목 | 값 |
|---|---|
| 실린더 수 | 4 |
| 배기량 | 97 |
| 마력 | 67 |
| 무게 | 2145 |
| 가속력 | 18 |
| 연식 | 80 |
| 출신 (1=미국, 2=유럽, 3=일본) | 3 |

예상 연비 약 32.9 mpg (실제 값 33.8 mpg)

## 배운 점

- 연비에 log 한 줄을 씌웠더니 0.82에서 0.85로 올랐다. 모델을 바꾸지 않아도 데이터를 다루는 방식만으로 점수가 달라지는 게 신기했다.
- 예측값이 실제 연비와 정확히 같은 경우는 거의 없었다. 그래서 "몇 % 맞췄다"가 아니라 "평균 약 2 mpg 틀린다"로 설명하는 게 맞다는 걸 이해했다.
- 예전 입력 코드와 새 코드를 섞어서 실행하다가 변수 이름과 입력 개수가 안 맞아 헤맸다. 모델이 바뀌면 입력창도 같이 바꿔야 한다는 걸 몸으로 배웠다.
- 맥북에서 라이브러리 설치 오류(`externally-managed-environment`)가 나서 막혔는데, 원인을 찾아 직접 해결했다.
